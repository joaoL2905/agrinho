01

O problema

Desperdício de água na agricultura

A água é essencial para a produção de alimentos. Porém, quando a irrigação não é planejada, pode ocorrer desperdício desse importante recurso.

Além de prejudicar o meio ambiente, o desperdício pode aumentar os custos da propriedade rural.

💧

Nosso desafio

Produzir alimentos e, ao mesmo tempo, preservar os recursos naturais.

Sobre o projeto

Este projeto foi desenvolvido para o Concurso Agrinho 2026, na categoria Programação Web com Inteligência Artificial.

O projeto apresenta o problema do desperdício de água na agricultura e mostra como a tecnologia pode ajudar na busca por uma produção mais sustentável.
